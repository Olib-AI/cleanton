# Contributing

Cleanton is closed-source, so this repository does not accept code pull
requests. The source code is not published here.

What helps us most:

- **Bug reports.** Open an [issue](https://github.com/Olib-AI/cleanton/issues)
  with your macOS version, the Cleanton version, and steps to reproduce. If it
  involves a scan result, tell us which category and recipe were involved.
- **Feature requests.** Tell us what you want Cleanton to clean or surface, and
  why. Real workflows are the most useful input.
- **Documentation fixes.** Typos and unclear steps in the `docs/` folder or this
  README are welcome as pull requests.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
